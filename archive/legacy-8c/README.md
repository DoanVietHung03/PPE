# Archived legacy eight-class experiment

Classes: helmet, vest, gloves, boots, no_helmet, no_vest, no_gloves,
no_boots. This taxonomy has no person class.

The experiment ran in August 2026. NaN.pth contains an eight-output
classification head but has 49,632 non-finite tensor values, so it is not
deployable. The archived configs and dataset are retained only for provenance
and future controlled experiments. Production code must not reference them.
